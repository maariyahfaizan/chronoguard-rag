These qualifications are retained rather than silently fixed. Engineering
compatibility is not independent scientific validation or authorization.

1. **G2-I4 -> I5 supersession.** The historical I4 document rejected silent aliasing
   and described a future schema revision. I5 explicitly adds a new, reversible,
   versioned synthetic transport profile. It leaves the original I4 artifact and
   direct-ingestion rejection intact. This is not a retroactive correction of I4,
   a real-ID-capable analyzer, or approved question equivalence.
2. **Synthetic aliases.** Canonical IDs remain present; each question has one alias
   across all eight cells. The inverse is an explicit map, not hash inversion.
   Distinct branches retain distinct registrations even when fictional text repeats.
3. **Authorization markers.** Historical runners do not enforce the adapter's
   blocked markers. Requests contain non-executable sentinel paths and runtime
   placeholders; there is no dispatcher. No real authority-provider service exists.
   Software fixture guards are not cryptographic authentication or an adversarial sandbox.

   the new projection adapter do not reclassify historical results or wire those
   runners automatically. A separately reviewed real invocation/replay path is needed.
